## How Plans Work
- Small changes: open a PR with a clear description — no formal plan needed
- Complex multi-step work: create an execution plan in `exec-plans/active/` before starting
- Completed plans move to `exec-plans/completed/` and are never deleted
- Decisions and tradeoffs are logged in the plan file itself
